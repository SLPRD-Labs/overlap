# overlap
A smart scheduling app that cross-references friend availabilities with activity wishlists to automatically find the perfect time to hang out. Built in Rust.

- **Availability calendar:** each user privately marks when they are free, unsure or busy.
- **Activities:** anyone can suggest an activity; interested users are matched on availability and the organizer picks the best date.
- **Polls:** settle the details (location, budget, carpooling...) directly within each activity.
- **Events:** once a date is set, attendees RSVP and get reminders.
- **Invite-only:** accounts are approved by an admin, who also handles moderation and maintenance.
